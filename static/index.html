Qualification Score Formulation

Score_{qual} = 0.40(Skills_{req}) + 0.10(Skills_{pref}) + 0.25(Exp) + 0.15(Edu) + 0.05(Certs) + 0.05(Projects)

Behavioral Gap Index (BGI) Formulation

BGI = 0.50(Qual\_Gap) + 0.30(Dec\_Gap) + 0.20(Expl\_Gap)

Transparent audit metric evaluating qualification-decision divergence. Audit indicator only, not proof of intentional bias.

Explanation Faithfulness Score (EFS)

EFS = 100 - Penalties(Contradicted Claims) - Penalties(Unsupported Claims)

Measures grounding of AI reasoning against verified candidate facts using Evidence Traceability.
